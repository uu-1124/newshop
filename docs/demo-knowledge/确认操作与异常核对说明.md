# 确认操作与异常核对说明

资料版本：DEMO-CONFIRM-20261113-V1，仅用于演示商城。

加入购物车、创建订单、取消未付款订单、提交退货申请都先生成确认卡。模型准备卡片不等于业务已经执行。买家需要核对实际商品、规格、数量、地址和金额，并点击确认按钮。

聊天中的“好的”“确认”“帮我付款”不替代确认按钮。卡片过期、会话被接管或业务条件变化时，应重新准备；不能静默按变化后的价格、规格或优惠下单。

取消订单只适用于本人当前允许取消的未付款订单。确认卡会显示完整订单号和订单金额。已付款订单不能沿此路径取消；支付与取消竞争后，以商城实际事务结果为准。

订单、库存、优惠券和积分由商城Java业务事务处理。重复点击确认、刷新、断线或服务恢复不能形成重复业务结果。

结果暂时不确定时显示核对状态。恢复只查询或封闭原操作编号，不重新执行一次业务。长期无法自动核对时由有权限员工查看和恢复原编号核对；不得根据AI文字手工认定下单、取消或退款成功。
