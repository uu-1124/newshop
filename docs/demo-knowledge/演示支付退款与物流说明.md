# 演示支付、退款与物流说明

资料版本：DEMO-SERVICE-20261113-V1。用途：本商城演示客服知识，适用于当前单商家演示环境。

商城支付为模拟支付。买家需要进入既有订单页面手动操作；智能体不会自动付款，不接收银行卡、支付密码或验证码。模拟支付成功表示演示订单的业务状态已更新，不表示真实扣款。

售后审核通过、收到退货、模拟退款完成是三个独立阶段。员工完成模拟退款会登记演示编号和处理状态，不调用真实资金渠道，不表示资金已到账。智能体只能查询和解释实际阶段，不能代替员工审核、收货或退款。

物流运单和轨迹由有权限员工维护，均为模拟物流。没有维护节点时，只能说明暂无模拟轨迹。轨迹不证明真实快递揽收、运输或签收，不保证预计到达日期。

目前没有在本资料中承诺次日达、限时退款到账、真实资金赔付、跨境配送或任何收费增值服务。涉及未公布的政策，请联系人工客服核实。
