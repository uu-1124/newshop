## 六 最新监控实现和验证边界

独立`agent-observability`进程以20秒加探针耗时的周期采样，存入强类型快照。快照缺失、无效或超过90秒即告警，关键依赖未就绪时`/readyz`返回503；`/livez`只表示进程存活。Redis/RabbitMQ失败独立告警，不因此取消文字/人工所需的数据库读取降级。探针不调用付费模型或执行业务。

当前监控包括：

- PG、portal/admin签名身份边界、gateway、私有MinIO、Milvus、Redis、RabbitMQ及云端探针；身份桥接要求正确服务签名被接受、仍由身份认证拒绝无Bearer请求。
- 云端内存可用率、实际Docker数据盘空闲率、11个预期容器运行/异常/OOM/重启计数。
- PG连接数、长事务/锁等待、API与worker的有界连接获取指标、槽位/排队、时钟不变量、通知积压。
- SSE初次订阅拒绝400/410的五分钟突增统计；该指标不计长连接完整持续时长，也不是完整断流质量指标。
- Java outbox到期、超60秒及多次重试；长期UNKNOWN按confirmed_at/created_at计算10分钟/1小时年龄，不再因核对更新updated_at而重置；同类最近三任务连续失败告警。
- 首段/排队/总时长仅统计仍保留的近24小时delta关联样本。当前样本数为0，P95为未知；被删除验收会话不再进入统计，不能将空样本当作快速响应。
