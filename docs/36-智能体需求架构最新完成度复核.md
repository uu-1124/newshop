## 3 四个明确的功能缺口

1. **语音输入和播报。** 运行OpenAPI缺转写与播报操作；买家附件当前只开放CHAT_IMAGE。录音7天和TTS7天配置、供应商适配器不等于实际用户流程。
2. **回答反馈。** 运行OpenAPI缺submitFeedback，聊天页没有完整点赞/点踩入口及保存链。
3. **人工模式买家发图。** [conversations.py](../mall-agent/app/application/conversations.py:498)在AI关闭且请求带附件时直接返回FEATURE_NOT_ACTIVE。员工发图和AI看图均已存在，不能代替此场景。
4. **结构化售后规则版本。** 原始Word明确要求版本、生效时间和提交时依据。当前[AgentAfterSaleStore.java](../mall-swarm/mall-mbg/src/main/java/com/macro/mall/order/AgentAfterSaleStore.java:21)固定`ITEM_NET_168H_DEMO_V1`及168小时窗口。申请记录rule_version字符串已有，但没有可管理的规则版本、生效与切换闭环。

## 4 本轮新增复现：失败的停止/转人工会冻结页面正文

当前[chat.vue](../mall-app-web/src/pages/agent/chat.vue:940)在发停止命令前把run放入blockedRuns；转人工同样提前加入。请求失败后没有删除该本地屏蔽记录。随后[agentStream.ts](../mall-app-web/src/services/agentStream.ts:35)不仅忽略delta，还将权威快照的正文钳制到原来已显示的文本。

复现使用实际Vue setup编译结果与明确的合成传输，不调用API、不写数据库：

1. 页面中有效任务为RUNNING，已显示“你好😀”。
2. stop或handoff返回合成503，后台任务仍为RUNNING、会话仍AI_ACTIVE。
3. 后续有效delta到达，页面仍只显示“你好😀”。
4. 再取得同一任务包含“后续正文”的更新权威快照，正文仍被本地屏蔽。

两个错误分支均复现。修复方向是区分“命令尚未确认”与“服务端已停止/接管”，失败后重查当前run及epoch，并按权威状态解除可继续生成的屏蔽，同时保持真正停止后旧输出不能回流。

证据：[audit-agent-20261114-control-failure-reproduction.log](../deployment/.run/audit-agent-20261114-control-failure-reproduction.log)。其中6项为4个既有集成场景加2个缺陷复现断言；通过表示复现条件成立，**不表示这两个缺陷已修复**。本轮仅审计，未修改这段代码。

上一轮流式修正已覆盖过期快照、Unicode偏移、重复/缺口和成功停止/接管等合成场景；实际浏览器停止、接管、断开重连、失败后恢复仍待完整验收。此前专用流式夹具准备日志为AssertionError，尚无该轮真实页面成功结论，不能把合成测试改写成浏览器验收。
